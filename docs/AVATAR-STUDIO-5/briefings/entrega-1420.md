## Decisões (registro #45)

- **#206** O pós v2 é DADO do look (`Look.pos`) atrás de `as6.pos_v2`, com degradação POR PASS centralizada no QualityManager (`passesPos`): econômico não paga composer nenhum, médio derruba só o bloom, alto libera a cadeia. `estudio` tem pós NEUTRO por contrato (benchmark de QA intocado) e `protegerPele` é obrigatório em todo grade (§1969). Context loss recria os composers (legado incluso — bugfix de caminho de erro, o frame ficava preto para sempre); falha de construção emite `p3d_pos_fallback` e cai no caminho legado. O "enum PHP" citado no mapa não existe para looks (look nunca persiste no AvatarConfig — #161); o enum que cresce é o de `Cenas3d.LUZES_3D` (localStorage, sanitizado).
- **#207** As lentes da Foto são registry puro (`LentesFoto.ts`) atrás de `as6.foto_lentes`: aspecto/câmera/look/terços como DADO; `capturarComLente` aplica e RESTAURA (shadow↑ + pós só na captura), e o `capturar()` corta a seco transições de câmera pendentes (uma captura é um frame — determinismo provado por hash de 2 capturas). DOF fica para P2. A UI é uma fileira de botões no palco; o Photo Studio 2D (`as6.cp_foto`) segue intocado.
